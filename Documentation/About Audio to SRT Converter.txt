# Audio to SRT Converter

This repository contains a Python script for converting audio and video files into
subtitle files (.srt, .vtt, .txt, .json) using OpenAI's Whisper model. The script is
equipped with a simple and user-friendly graphical user interface (GUI), allowing easy
operation without the need for command-line interaction.

## Features
- **Easy-to-use GUI**: Queue up audio/video files, whole folders, or YouTube URLs and
  transcribe them all in one batch.
- **Whisper Model Integration**: Auto-selects the fastest available backend -
  mlx-whisper (Apple Silicon), faster-whisper (CUDA/CPU), or openai-whisper (always
  available fallback).
- **Local Processing**: Transcription always runs entirely on-device. The only network
  activity is the one-time audio download when a YouTube URL is used as input.
- **Long-file support**: Files over 20 minutes are automatically split into chunks so
  memory usage stays bounded, with incremental per-chunk progress.
- **Wide format support**: MP3, WAV, M4A (audio), MP4, MOV (video - audio is extracted
  automatically); outputs .srt, .vtt, .txt (plain transcript), and/or .json.
- **Customizable Model Selection**: Choose from different Whisper model sizes to
  balance between performance and accuracy.

## Dependencies
- Python 3.10 or higher
- Tkinter
- ffmpeg
- See `requirements.txt` (required) and `requirements-optional.txt` (mlx-whisper /
  faster-whisper, for faster transcription)

## Installation
See `Documentation/How to install dependencies.txt` for full setup steps (macOS and
Windows).

## Usage
```sh
python main.py
```
1. Add files via **Add Files...**, a whole folder via **Add Folder...**, or a video URL
   via **Add YouTube URL...**.
2. Select the desired Whisper model size and output format(s).
3. Click **Transcribe Queue**. Each item's subtitles are written next to its source
   file (or into `~/Downloads`, named after the video's title, for a URL).
