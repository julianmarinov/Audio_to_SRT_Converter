Here is a simple guide to set up the environment to run the Audio to SRT Converter script on both Mac (including Apple Silicon / M1/M2/M3) and Windows:

### Dependencies List:
1. Python 3.9+ (3.12 recommended)
2. Tkinter (usually comes with Python)
3. openai-whisper (PyPI package name — do NOT `pip install whisper`, that is an unrelated package)
4. torch (PyTorch — provides CUDA, Apple Silicon MPS, or CPU acceleration automatically)
5. ffmpeg (external binary, required by Whisper for audio decoding)

### Installation Instructions:

#### For Both Mac and Windows:

**Python**:
- Go to the [official Python website](https://www.python.org/downloads/) (or on Mac, `brew install python@3.12`).
- Run the installer and follow the instructions. Make sure to check the box that says "Add Python to PATH" during installation on Windows.

**Set up a virtual environment (recommended)**:
```
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```
This installs `torch` and `openai-whisper` (correct package name) from `requirements.txt`.

**ffmpeg**:
- On Mac: `brew install ffmpeg` (requires [Homebrew](https://brew.sh/))
- On Windows: download a build from [ffmpeg.org](https://ffmpeg.org) and add it to your PATH.

**Tkinter**:
- On Windows, Tkinter is included with the Python installer.
- On Mac, if `import tkinter` fails, run:
  ```
  brew install python-tk@3.12
  ```
  (match the version suffix to your Python version)

Once everything is installed, run the app with:
```
python main.py
```

### Apple Silicon (M1/M2/M3) notes
- No Rosetta / x86_64 workaround is needed — `torch` and `openai-whisper` both ship native arm64 wheels.
- The script auto-detects the best available device at runtime: NVIDIA CUDA GPU > Apple Silicon GPU (MPS) > CPU. You can confirm which device was picked from the "Loading model on ..." status message, or via the Help button in the app.
- The "large" model is fairly slow even on an M1 Pro GPU; "small" or "medium" are a good speed/accuracy tradeoff for everyday use.

### Additional Notes:
- If you are not able to run `pip` commands directly, you might need to use `python -m pip` instead.
- If any errors occur relating to missing packages, they can typically be installed using `pip install package_name`.
